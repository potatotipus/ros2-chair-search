# 課題説明

## 概要・目的

ROS 2とGazeboを使用し、ロボットが障害物を避けて移動し、カメラ画像から椅子を認識して停止するシミュレーションを作成した。移動にはNav2、物体認識には学習済みYOLO11sモデルの推論を利用した。自律移動とAIによる画像認識を連携させ、認識結果によってロボットの行動を変えることを目的とした。

## 工夫した点

認識を安定させるため、椅子全体が写る位置に確認地点を設定し、4本脚の単純な椅子モデルを使用した。また、1画像だけで成功とせず、複数画像で椅子を確認してから停止するようにした。計算負荷を抑えるために小さな部屋を用意し、画面に検出枠とタスク状態を表示して動作を確認しやすくした。

## 結果

確認地点への自動移動、椅子の繰り返し検出、探索の終了を確認できた。今回の探索範囲は事前設定した1つの確認地点とその周囲で、地図は部屋の固定物から事前生成した。AIモデルの追加学習は行わず、学習済みモデルの推論を使用した。
